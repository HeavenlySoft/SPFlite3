# SPFlite3
SPFlite3 V3.3.26055 frozen as of Feb 24, 2026 by *George Delucas*
* 2026-11-09 **MP**  - *Created this public SPFLite3 repository to document copying all files in George Delucas' SPFLite3.v3.3.26055.zip (downloaded from SPFLite.com, Georg'es SPFLite website as he indicated that version is frozen (as of Feb 24, 2026 = Julian date 26055) and he will not add any more bug fixes or enhancements to it, instead moving on to port the SPFLIte3 code written in PowerBasic to Microsoft Visual Basic .NET (aka MS VB .NET)*

* 2026-11-09 **MP**  - *Eventhough George made the SPFLite3 software open source code, until I have his permission, his code will stay as a private GitHub project here under the repository name SPFLite3.3 (private) and any bug fixes subsequent to that release and repository will go against repository SPFLite3.4, which is currently private as of this writing but will be made public once I have heard back from George.*

* 2026-11-09 **MP**  - *I am not volunteering to take over support of SPFLite3.3, however since I use SPFLite3.3 myself on my PC, I am keeping the SPFLite3.4 repository for bug fixes that I need to make for bugs I myself run into.*

* 2026-11-09 **MP**  - *One bug already reported in 3.3 and fixed in 3.4 is BOUNDS 9 MAX makes subsequent FIND/CHANGE primary commands fail (won't find anything)*
